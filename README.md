## 설치는 3단계

**1. 받아서 더블클릭**
브라우저가 "일반적으로 다운로드되지 않습니다"라고 하면 **··· → 유지 → 삭제 옆 ∨ → 그래도 계속**. 파란 "PC 보호" 창이 뜨면 **추가 정보 → 실행**.

**2. 다음, 다음, 마침**
뿌리가 화면에 떨어져요.

**3. 이름 정하고 첫 대화**
AI 연결은 건너뛰어도 돼요. 뿌리가 이름·하는 일·근무 시간을 물어보면 답해 주세요. 회사를 안 다니면 "안 다녀".

그다음은 **뿌리를 우클릭**하면 전부 나와요. 끝.

<details>
<summary><b>AI 연결하기 (선택)</b></summary>
<br>

AI를 연결하면 뿌리와 대화하고, 말로 일정·할 일을 넣고, 메모를 정리할 수 있어요. 연결 안 해도 일정·할 일·메모는 직접 적어서 그대로 쓸 수 있어요.

**가장 쉬운 방법: Google (무료)**

1. 뿌리 우클릭 → 설정 → **AI** 탭 → Google 줄의 **키 받기**를 누르면 브라우저가 열려요.
2. 구글 계정으로 로그인 → **Create API key**(API 키 만들기) → 나온 긴 글자를 복사.
3. 설정 창으로 돌아와 **붙여넣기** → **확인**. "연결됨"이 뜨면 끝.

이 키는 비밀번호 같은 거라 남에게 보내지 마세요. 무료 등급에서는 대화 내용이 Google 서비스 개선에 쓰일 수 있어요. 개인정보나 회사 기밀은 대화에 넣지 마세요.

**ChatGPT나 Claude를 구독 중이면**

같은 화면의 ChatGPT·Claude 줄에서 **설치 → 로그인**을 차례로 누르면 돼요. 설치는 검은 창이 열려 진행되고, 로그인은 브라우저에서 해요. 키 복사는 필요 없어요. 구독량을 같이 써요.

</details>

<details>
<summary><b>메뉴 설명</b></summary>
<br>

뿌리를 **우클릭**하면 메뉴가 나와요. 두 번 클릭하면 바로 대화예요.

| 메뉴 | 하는 일 |
| --- | --- |
| 대화하기 | 뿌리와 이야기. "다음 주 화요일 3시 치과"처럼 말하면 일정으로 기억해요 (AI 연결 필요) |
| 일정 | 일정 창. 직접 넣고 고쳐요. 반복 일정, D-day도 돼요 |
| 할 일 | 오늘 할 일 목록. 끝내면 체크 |
| 메모 | 새 메모는 첫 줄이 제목, Ctrl+S 저장. 메모 목록에서 **책으로 보기**(깔끔한 한 페이지), **AI로 정리**(요약본, AI 연결 필요) |
| 화면 점검 | 화면 일부를 골라 AI에게 보여 주고 묻기 (AI 연결 필요) |
| 밥 주기 | 점심 알림 시간에 배고프다고 해요. 밥을 주면 좋아하고, 얼마 뒤 똑을 남겨요. 똑은 클릭하면 치워져요 |
| 설정 | 이름·성격·말투, AI 연결, 근무 시간·알림. **사용법** 탭에 자세한 설명이 있어요 |
| 숨기기 | 잠깐 감춰요. 다시 보려면 작업 표시줄 오른쪽 아래 트레이의 뿌리 아이콘 우클릭 → 다시 보이기 |

뿌리를 끌어서 원하는 자리에 놓을 수 있고, 모니터가 두 대면 알아서 건너다녀요. 버튼을 누르지 않고 뿌리 위에서 마우스를 좌우로 문지르면 쓰다듬어짐이에요.

</details>

<details>
<summary><b>업데이트</b></summary>
<br>

새 버전이 나오면 뿌리가 말풍선으로 알려 줘요. **업데이트**를 누르면 받아서 설치하고 스스로 다시 켜져요. 일정·메모는 그대로 남아요. 직접 확인하려면 설정 → 기타 → **업데이트 확인**.

</details>

<details>
<summary><b>문제가 생기면</b></summary>
<br>

- **뿌리가 안 보여요**: 작업 표시줄 오른쪽 아래 트레이(∧ 표시)에서 뿌리 아이콘 우클릭 → 다시 보이기. 그래도 없으면 시작 메뉴엜 Computer Pet을 다시 실행하세요.
- **이상하게 동작해요**: 우클릭 → 종료 후 다시 실행. 그래도 그러면 아래 로그 폴더의 파일을 보내 주세요. 탐색기 주소칸에 그대로 붙여넣으면 열려요.

```
%LOCALAPPDATA%\ComputerPet\Logs
```

- **제거**: Windows 설정 → 앱 → Computer Pet → 제거. 일정·메모는 지우지 않아서 다시 설치하면 그대로예요. 완전히 지우려면 `%LOCALAPPDATA%\ComputerPet` 폴더를 지우세요.
- 내 일정·메모는 내 컴퓨터에만 저장돼요. 매일 자동 백업되고, 설정 → 백업에서 되돌릴 수 있어요.

</details>
