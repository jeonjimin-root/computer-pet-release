<details>
<summary><b>설치</b></summary>

<br>

1. 위의 **설치 파일 받기**를 누릅니다.
2. 받은 파일을 열고 <kbd>다음</kbd> → <kbd>마침</kbd>을 누릅니다.
3. 안내 창이 묻는 대로 이름을 짓고 AI를 연결합니다.

설치가 끝나면 펫을 **우클릭**해 메뉴를 엽니다. 자세한 사용법은 설정 → 사용법 탭에 있습니다.

</details>

<details>
<summary><b>경고가 뜨면</b></summary>

<br>

개인이 만든 프로그램이라 받을 때와 실행할 때 한 번씩 뜰 수 있습니다.

| 이런 화면이 나오면 | 이렇게 누릅니다 |
| --- | --- |
| 브라우저의 "일반적으로 다운로드되지 않습니다" | <kbd>···</kbd> → <kbd>유지</kbd> → 삭제 옆 <kbd>∨</kbd> → <kbd>그래도 계속</kbd> |
| 파란색 "Windows의 PC 보호" 창 | <kbd>추가 정보</kbd> → <kbd>실행</kbd> |

</details>

<details>
<summary><b>AI 연결</b></summary>

<br>

둘 중 하나만 연결하면 됩니다. 연결해야 다음 단계로 넘어갑니다.

| | 비용 | 누르는 순서 |
| --- | --- | --- |
| **Google** | 무료 | <kbd>키 받기</kbd> → 구글 로그인 → <kbd>Create API key</kbd> → 복사 → <kbd>붙여넣기</kbd> |
| **ChatGPT · Claude** | 구독 중일 때 | <kbd>설치</kbd> → <kbd>로그인</kbd> |

> [!IMPORTANT]
> 받은 키는 비밀번호와 같습니다. 다른 사람에게 알려 주지 마십시오.<br>
> 무료 등급에서는 대화 내용이 구글 서비스 개선에 쓰일 수 있으니, 회사 자료는 입력하지 마십시오.

</details>

<details>
<summary><b>뿌리가 하는 일</b></summary>

<br>

- 일정, 할 일, 메모를 챙기고 시간에 맞춰 알려 줍니다.
- 말을 걸면 대답합니다. "화요일 3시 치과"라고 하면 일정으로 기억합니다.
- 밥을 주고 쓰다듬으며 같이 지냅니다.
- 일정과 메모는 내 컴퓨터에만 저장됩니다.

</details>
